===============================================================================
  SISTEMA DE GESTION DE FARMACIA EN LINEA
  Evidencia GA7-220501096-AA2-EV01. Codificacion de modulos del software

  COMO EJECUTAR EL PROYECTO
===============================================================================

Aplicacion web Java con dos zonas:

  TIENDA PUBLICA   No exige cuenta. Pagina de inicio, catalogo por categorias,
                   detalle de producto y carrito de compras. La cuenta se pide
                   solo al confirmar el pedido, y quien se registra recibe el
                   rol Cliente.

  PANEL DE GESTION Los 13 modulos derivados del modelo relacional mas el
                   tablero de indicadores. Reservado a los perfiles
                   Administrador y Farmaceutico.

Construida con Servlets, JSP y JDBC sobre una arquitectura de tres capas:
IGU, Logica y Persistencia.

El codigo fuente esta en la carpeta FarmaWeb.
La version previa del modulo de medicamentos en Node.js se conserva en la raiz
(script.js, config, controllers, public) como evidencia del avance anterior.


-------------------------------------------------------------------------------
  QUE NECESITA INSTALADO
-------------------------------------------------------------------------------

  1. JDK 17 o superior          https://adoptium.net/temurin/releases/
  2. Apache Maven 3.9 o superior  https://maven.apache.org/download.cgi
  3. MySQL o MariaDB en ejecucion (XAMPP funciona sin ajustes)
  4. Conexion a internet la primera vez que se ejecute Maven

Verifique la instalacion en una terminal NUEVA:

      java -version
      mvn -v

Si Maven reclama la variable JAVA_HOME, definala apuntando a la carpeta del JDK.


-------------------------------------------------------------------------------
  PASO 1. INICIAR LA BASE DE DATOS
-------------------------------------------------------------------------------

Abra el panel de control de XAMPP y pulse Start en la fila MySQL.


-------------------------------------------------------------------------------
  PASO 2. CREAR LA BASE DE DATOS CON DATOS DE PRUEBA
-------------------------------------------------------------------------------

Opcion A, por consola:

      C:\xampp\mysql\bin\mysql.exe -u root < FarmaWeb\src\main\resources\sql\bd_farmacia_completa.sql

Opcion B, por phpMyAdmin:

      Abra http://localhost/phpmyadmin
      Vaya a la pestana SQL
      Pegue el contenido del archivo:
          FarmaWeb\src\main\resources\sql\bd_farmacia_completa.sql
      Ejecute

El script crea la base bd_farmacia con sus 13 tablas y carga datos de prueba.
Al terminar muestra una tabla con el conteo de registros de cada tabla.

IMPORTANTE: el script comienza con DROP DATABASE IF EXISTS bd_farmacia.
Si ya existe una base con ese nombre, sus datos se reemplazan.


-------------------------------------------------------------------------------
  PASO 3. AJUSTAR LA CONEXION SOLO SI ES NECESARIO
-------------------------------------------------------------------------------

El archivo:

      FarmaWeb\src\main\resources\db.properties

viene configurado con el usuario root sin contrasena, que es el valor por
defecto de XAMPP. Si su MySQL tiene contrasena, escribala en la linea:

      farmacia.db.password=


-------------------------------------------------------------------------------
  PASO 4. COMPILAR Y EJECUTAR
-------------------------------------------------------------------------------

      cd FarmaWeb
      mvn clean package
      mvn cargo:run

Maven descarga Tomcat 10.1 automaticamente. No hace falta instalarlo aparte.
La primera ejecucion tarda unos minutos porque baja las dependencias.

Espere a que aparezca en la terminal:

      Tomcat 10.1.30 started on port [8080]

Para detener el servidor: Ctrl+C en esa terminal.


-------------------------------------------------------------------------------
  PASO 5. ABRIR LA APLICACION
-------------------------------------------------------------------------------

      http://localhost:8080/farmaweb

Se abre la tienda publica: puede recorrer el catalogo y armar el carrito sin
registrarse. Para confirmar un pedido se crea una cuenta o se ingresa.

  Usuarios de prueba:

      Administrador   admin@farmacia.com          admin123
      Farmaceutico    carlos.ruiz@farmacia.com    farma123
      Cliente         laura.gomez@correo.com      cliente123

Administrador y Farmaceutico entran al panel de gestion; el Cliente entra a
Mi cuenta. Un cliente no puede abrir los modulos de gestion ni escribiendo la
direccion: el sistema lo devuelve a su cuenta.

Las contrasenas se almacenan cifradas con SHA-256, nunca en texto plano.


-------------------------------------------------------------------------------
  COMO SE ASIGNAN LOS ROLES
-------------------------------------------------------------------------------

      Cliente        Se asigna solo, al registrarse en la tienda
      Farmaceutico   Lo asigna el administrador, desde el modulo de Usuarios
      Administrador  Lo asigna el administrador, desde el modulo de Usuarios


-------------------------------------------------------------------------------
  ALTERNATIVA SIN COMPILAR
-------------------------------------------------------------------------------

En la raiz de este paquete se incluye el archivo ya compilado:

      farmaweb.war

Si prefiere no usar Maven, copie ese archivo a la carpeta webapps de un
Apache Tomcat 10.1 instalado y abra http://localhost:8080/farmaweb
De todas formas debe realizar antes los pasos 1 y 2.


-------------------------------------------------------------------------------
  ADVERTENCIA SOBRE EL SISTEMA OPERATIVO
-------------------------------------------------------------------------------

La ejecucion con Maven esta configurada para Windows. El archivo
FarmaWeb\pom.xml instala y ejecuta Tomcat en la ruta C:\farmaweb-servidor
porque la carpeta original del proyecto contiene tildes y guiones especiales
que corrompen la linea de comandos con que se lanza el servidor.

En Linux o macOS esa ruta no existe. En ese caso, use el archivo farmaweb.war
sobre un Tomcat 10.1 instalado, o cambie el valor de la propiedad dir.tomcat
en FarmaWeb\pom.xml por una ruta valida del sistema.

Se recomienda descomprimir este paquete en una ruta corta y sin tildes,
por ejemplo C:\ModuloFarma

-------------------------------------------------------------------------------
  FORMULA MEDICA Y FORMAS DE PAGO
-------------------------------------------------------------------------------

Los medicamentos marcados como controlados exigen adjuntar la formula medica
en el carrito antes de poder confirmar el pedido. Se aceptan archivos PDF,
JPG o PNG de hasta 5 MB.

Los archivos NO se guardan dentro de la aplicacion, porque esa carpeta se
borra en cada despliegue. Se guardan en la carpeta que indica el parametro
carpetaRecetas de FarmaWeb\src\main\webapp\WEB-INF\web.xml. Si se deja
vacio, se usa la subcarpeta farmaweb-recetas del directorio del usuario.

Al confirmar el pedido, el cliente escoge la forma de pago e indica el monto:

      PSE                       Pago en linea. Queda aprobado de inmediato.
                                Se exige el valor exacto.
      Contraentrega efectivo    Se paga al recibir. Puede indicar un monto
                                mayor y el sistema calcula el cambio.
      Contraentrega datafono    Se paga al recibir con tarjeta. Valor exacto.

En todos los casos el pedido queda en estado PENDIENTE hasta que un
farmaceutico lo revise y lo confirme.


-------------------------------------------------------------------------------
  LOS 13 MODULOS DE GESTION Y SU TABLA
-------------------------------------------------------------------------------

      Roles                  /roles           TblRol
      Usuarios               /usuarios        TblUsuario
      Clientes               /clientes        TblCliente
      Farmaceuticos          /farmaceuticos   TblFarmaceutico
      Productos              /productos       TblProducto
      Inventario por lotes   /lotes           TblLoteProducto
      Favoritos              /favoritos       TblFavorito
      Pedidos                /pedidos         TblPedido
      Detalle de pedidos     /lineas          TblLineaPedido
      Formulas medicas       /formulas        TblFormulaMedica
      Historial              /historial       TblHistorial
      Pasarelas de pago      /pasarelas       TblPasarelaPago
      Transacciones          /transacciones   TblTransaccionPago

Mas el tablero de gestion en /panel, que reune los indicadores del sistema.

Las cinco categorias del catalogo son: Medicamentos, Cuidado personal,
Botiquin, Bebes y Nutricion. Se asignan a cada producto desde el modulo de
Productos, junto con el nombre del archivo de su fotografia.
